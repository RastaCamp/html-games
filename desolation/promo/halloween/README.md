# Halloween campaign short

`desolation-halloween.mp4` — a 30s vertical (1080x1920) ad short for the Halloween
campaign, built from this game's own art (`visuals/`) and its real title theme
(`title.mp3`), with captions.

`build-script-reference.mjs` is a copy of the actual build script for reference — it
was run from a shared `promo-videos/halloween-shorts/` workspace (it also builds the
TerrorWell and Campfiya Halloween shorts in one pass, referencing all three apps'
assets by absolute path), not meant to run standalone from inside this repo.
