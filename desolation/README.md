# Desolation

A slow-burn survival descent. Atmosphere over hand-holding — you're dropped in with almost nothing explained, and the game means it.

**Play it:**
- 🌐 https://desolation.rastacamp.com
- 🎮 https://rastacamp.itch.io/desolation

**Promo:** `promo/halloween/desolation-halloween.mp4` — Halloween seasonal trailer.

## Repo layout

- `site/` — the live build source (deployed to Cloudflare Pages, `desolation.rastacamp.com`). Includes the full shared rastacamp.com music library.
- `publish-web/` — a trimmed copy used for itch.io / Game Jolt / Newgrounds / GX.games uploads. Same game, cut down to 5 on-theme tracks (dystopian siren, gothic, end, outrebirth, survive) instead of the full 230MB shared library — both the audio files and the in-game track picker were trimmed together so nothing is ever offered that isn't there.
- `manual-uploads/` — packaged zips + listing copy for the platforms without a push API (Game Jolt, Newgrounds, GX.games).
